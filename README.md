# AnSpace Battle — Public Preview

This is the separate, public **preview-only** repository for AnSpace Battle.

**Status:** Preparing a safe, isolated demonstration. The playable v5.1 build has **not** been released here.

- The main game repository remains private.
- No production database, live API keys, or private source files are included.
- Third-party character artwork and animations will not be published unless public redistribution rights are verified.
- Real-time multiplayer has not yet been verified against an isolated staging backend.

The public preview is not a production release. This repository intentionally contains only the public landing page until the security and asset-rights checks are complete.
